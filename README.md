# 岁邻 uni-app 前端演示版

> 让牵挂更近，让生活更安心。

岁邻是一款连接长辈、家人与社区服务的生活关怀小程序，聚合健康状态、日常提醒、家庭协作、照护管理与生活服务。

## 页面
- 品牌入口页
- 登录 / 注册 / 找回密码
- 长辈端首页
- 家人端首页
- 健康中心
- 照护管理
- 服务中心
- 我的
- 提醒设置
- 家庭成员与邀请
- 照护任务
- 设备、通知、隐私、帮助、关于

## 当前状态
目前以前端演示为主，注册、设置、任务等流程使用本地存储或 Mock 数据，不依赖真实后端。

## 已预留 API
见 `api/index.js` 与 `utils/request.js`。

## HBuilderX
直接导入整个项目目录运行。

## CLI
```bash
npm install
npm run dev:h5
npm run dev:mp-weixin
```

## 微信小程序
在 `manifest.json` 填入你的微信小程序 AppID。
