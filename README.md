# 岁邻 · 家庭生活关怀小程序

岁邻连接长辈、家人与社区服务，让牵挂更近，让生活更安心。

## 当前架构

### 前端

- uni-app / Vue 3
- 微信小程序
- 家属注册 / 登录
- 添加长辈
- 邀请长辈一键绑定
- 长辈端大按钮简洁模式
- 提醒、健康、设备等页面已开始接真实后端 API

### 后端

目录：`server/`

技术栈：

- Java 21
- Spring Boot 3
- MySQL 8
- Redis
- MyBatis-Plus
- Sa-Token
- Docker

核心业务链路：

```text
家属注册/登录
  ↓
添加长辈
  ↓
生成邀请
  ↓
长辈点击邀请
  ↓
一键绑定
  ↓
服务端签发长辈端 clientToken
  ↓
长辈端读取提醒 / 完成提醒 / SOS
```

## 数据原则

- 年龄不保存，统一通过出生日期计算。
- 健康数据必须标记来源。
- 设备状态必须来自设备记录。
- 提醒必须由家属实际创建。
- 页面不应写死姓名、年龄、健康状态、设备在线状态等业务数据。

## 本地后端启动

```bash
cd server
docker compose up --build
```

后端默认：`http://127.0.0.1:8080`

Swagger：`http://127.0.0.1:8080/swagger-ui.html`

详细说明见 `server/README.md`。
